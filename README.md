# Plataforma de Gestión de Usuarios y Servicios

Este proyecto es una plataforma web desarrollada con **Angular 19** y **TailwindCSS**, que permite registrar usuarios, asignarles roles y gestionar funcionalidades relacionadas con asesorías contables. Además, cuenta con protección de rutas, navegación dinámica y despliegue en GitHub Pages.

## 🚀 Características principales

- Registro de usuarios (nombre, correo, rol).
- Roles: Administrador y Visualizador.
- CRUD completo para usuarios (crear, editar, eliminar).
- Protección de rutas para restringir acceso según el rol.
- Almacenamiento local (`localStorage`) para simular base de datos.
- Formulario de contacto.
- Diseño responsive con TailwindCSS.
- Navegación fluida con rutas standalone.
- Despliegue estático en GitHub Pages.

## 📦 Tecnologías utilizadas

- Angular 19 (standalone components)
- TailwindCSS
- localStorage (sin backend)
- GitHub Pages
